Registro de eventos

Como ler: "buraco" = segundos seguidos sem chegar nenhum dado. Se todos os servidores têm buracos/quedas nos mesmos horários → é o Wi-Fi/rede do aparelho. Se só um servidor IPTV cai → é esse servidor ou o caminho até ele. Buracos em intervalos regulares (ex.: a cada 2–3 min) costumam ser o Android fazendo economia/varredura do Wi-Fi. Nada aqui usa banco de dados nem salva nada no aparelho — "Apagar tudo" só zera a tela e os números.
